🍽️ Bistro Bliss – Restaurant Website

📌 About the Project
Bistro Bliss is a restaurant website developed using HTML and CSS. It showcases restaurant information, delicious food items, and contact details through a clean and attractive design.

✨ Features
- Simple and attractive user interface
- Navigation bar for easy browsing
- Restaurant introduction section
- Food menu with images
- Contact information section
- Responsive layout for different screen sizes

🛠️ Technologies Used
- HTML5
- CSS3

📂 Project Structure
Restaurant/
├── index.html
├── style.css
└── images/

🚀 How to Run Locally
1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
